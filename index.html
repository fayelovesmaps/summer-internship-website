things I got to work on

A short recap of the main projects I learned from and built this summer.

build a daily updated dashboard to track model promotion by scraping aggregator website

web scrape data using requests and Playwright to compare model pricing

create a demo of audio models, Qwen TTS and CosyVoice for food delivery client

create a poster and video generation webpage integrating Qwen and Happy Horse for non-profit client

analyze Qwen Image 3.0’s performance in object removal with tests I produced and generated prompts for good results

run the DeepSWE and Vercel Next.js coding benchmarks on the newly released Qwen3.8

use Wonderclip to generate model use case examples and compare performance with competitors

the lessons

things I learned this summer

a NON-exhaustive list of skills gained that I will keep with me

1

Maxing out my agents

Creating skills from my ideas or GitHub repos, letting it work in my browser, and editing User Profile or Collaboration Style in settings to personalize the agent.

2

Using the terminal and working with CLI

Git commands, running agents like Qoder, aliyun CLI, GitHub CLI…etc.

3

Model training basics

Cleaning training data, data labelling, and LoRA on Alibaba Cloud's Platform for AI.

4

Using AI models in different scenarios

Direct API calls, using CLI, desktop apps, versus integrating AI harnesses.

5

Vibe coding

Using agents to plan with me, optimizing prompts to execute for better output, and wrapping resources on Github into skills for better UI

the rest of life

things I enjoyed beyond the 9-5

I will miss all my new friends and the adventures we embarked on

A few Saturdays scattered across my summer

Time by the coast

Now convinced that driving 3+ hours for a weekend hangout with friends isn't outrageous. Aesthetics aside, wearing trashbags at the beach was a genius idea. Many in-n-out burgers eaten.

Saturday, July 18

Trip to Santa Cruz

Walked around the pier and boardwalk. Stumbled upon a group of sea lions napping. Celebrated Jude Bellingham scoring the 6th goal in the final minute of the World Cup third place match

Saturday, July 25

Hiked up Muir Woods

Ate Magnum ice cream bars and Drizzelicious rice cakes as a pre-hike snack. Carried a bag of grapes as we trekked up the mountain. The redwoods were unimaginably tall.

Wednesday, July 29

Giants vs. Brewers Game

Went to my first baseball game EVER with front-row seats. High fived Lou Seal despite wearing their opponent's jersey. Devoured unlimited ice cream (with toppings) and used up all my sunscreen.

Sunday, August 16

Explored Stanford at night

The last Sunday of the summer. A friend gave me a tour of campus on a 4km run. Took in the night views from a high point and huddled around a warm air vent as we talked about life.
